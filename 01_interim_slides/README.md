# 期中簡報 Prompt

本資料夾用於整理：

期中審查簡報、工作成果簡報、進度報告簡報及業主審查簡報相關之 AI 協作 Prompt。

---

# 主要用途

- 期中審查簡報
- 工作成果簡報
- 計畫進度簡報
- KPI 圖卡
- 制度分析簡報
- 技術成果頁面
- 長官簡報版型

---

# 常見簡報類型

- 國際管理趨勢
- 國內制度盤點
- 技術調查成果
- 污染途徑分析
- 工作統計圖表
- 執行進度圖卡

---

# 使用原則

1. 簡報以「審查閱讀」為核心。
2. 避免單頁資訊量過高。
3. 優先圖卡化與流程式呈現。
4. 技術內容需兼顧可閱讀性。
5. 圖表與數據須確認正確。
