# 期中書面報告 Prompt

本資料夾用於整理：

期中書面報告、技術章節、制度分析、管理評估及正式報告文字相關之 AI 協作 Prompt。

---

# 主要用途

- 期中書面報告
- 國際管理趨勢撰寫
- 國內制度盤點
- 技術分析段落
- 可行性評估
- 制度分析
- 管理建議
- 圖表文字說明

---

# 常見報告類型

- PFAS 管理趨勢
- PBDE 制度分析
- 農地污染風險
- 污染途徑分析
- 技術調查成果
- 制度可行性評估

---

# 使用原則

1. 報告應保持正式技術文字。
2. 不得自行推論污染來源。
3. 制度名稱與法規用語應保持正式。
4. AI 內容須回查原始資料。
5. 應避免過度簡化制度邏輯。
