# 期中報告 AI 協作模板庫

本 repository 用於整理期中報告、期中簡報及相關技術文件之 AI 協作 Prompt 與報告模板。

本資料庫以「正式政府技術報告」為主要輸出方向。

---

# 主要用途

* 期中報告撰寫
* 期中簡報生成
* 國際管理趨勢整理
* 國內制度盤點
* 可行性評估
* 圖表素材整理
* 演講稿生成

---

# 使用原則

1. AI 不可取代正式技術判斷。
2. 制度與法規應回查原始來源。
3. 不得自行推論污染來源。
4. 正式報告應維持技術性與制度導向。
